# Lool & Jool

Тёплые технологии для детей и семьи. Сайт проекта и демо ИИ-репетитора для начальной школы (1–4 класс).

- Уроки ведут герои — Обезьянка, Ленивец и другие; главный наставник ребёнка — Джул.
- Репетитор не решает за ребёнка, а подводит к ответу вопросами.
- Сейчас на сайте демо: ответы выбираются кнопками, ИИ пока не подключён.

Lool & Jool — самостоятельный проект и часть экосистемы [Лаборатории Счастья](https://gokosmos.github.io/LabS/).

## Запуск

```bash
npm install
npm run dev
```

Сайт публикуется на GitHub Pages при каждом изменении ветки `main`: `.github/workflows/deploy-pages.yml`.
