# Lool & Jool

Самостоятельный проект Юлии Космос: тёплые технологии для детей и семьи. Часть экосистемы
Лаборатории Счастья (репозиторий GoKosmos/LabS), но автономный сайт со своим адресом:
https://gokosmos.github.io/lool-jool/

Общение с Юлией — на русском языке.

## Что уже решено

- **Возраст:** начальная школа, 1–4 класс (ФГОС НОО).
- **Педагогика:** герой не решает за ребёнка, а подводит к ответу вопросами. Ошибка — это подсказка
  и вторая попытка, а не минус. Без оценок, хвалим старание. Нейтральные формулировки без «готов(а)».
- **Герои:** уроки ведут разные персонажи, как в Duolingo — Обезьянка (любопытная, весёлая),
  Ленивец (спокойный, терпеливый) и другие. **Джул — главный наставник-проводник** ребёнка.
- **Стиль:** «Игровой» — яркие цвета, чёрная обводка, «наклеечные» тени, шрифты Unbounded + Rubik.
- **Форматы обучения, этап 1:**
  1. Помощь с домашкой (`src/TutorDemo.jsx`);
  2. Путь знаний — карта тем, уроки по 7–15 минут, путь ведёт Джул (`src/KnowledgePath.jsx`);
  3. Подготовка к контрольной — вкладки «Тест · Карточки · Памятка» (`src/ExamPrep.jsx`). В итоге теста
     **показываем счёт** (верно X из N: с первой попытки / со второй / не получилось) — это решение Юлии,
     для подготовки к контрольной счёт нужен. Плюс «Что получается» / «Над чем поработать» по темам.
     «Работа над ошибками» — повторный круг только по заданиям, не решённым с первой попытки.
  Следующие форматы (не решено): тренажёры-игры, «Научи героя», сказка-квест, «Почемучка»,
  семейные задания, минутка настроения.
- Сейчас всё — **демо** на заготовленных сценариях. Настоящий ИИ — следующим шагом через серверную
  функцию Supabase (ключ API хранится только на сервере, не в коде сайта).
- В отчёте для родителя — наблюдения, а не оценки ребёнка.

## Безопасность детей

Защитный протокол (телефон доверия 8-800-2000-122, сигнал родителю), никаких лишних данных о ребёнке,
безопасные темы — см. промпт репетитора. Об игрушках: никаких сильных магнитов и ношения на шее во сне.
